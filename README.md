## 🇬🇧 English Version

### 🎮 Overview
**Tiles Journey** is a lightweight, mobile-optimized strategy game. Players manage resources, level up infinitely, and embark on expeditions where every tile chosen yields materials or presents dangers. Craft advanced components in the Hub to unlock unique items!

### ✨ Key Features
* **Infinite Progression:** Gain +1 EXP on every choice. Level requirement grows with each level.
* **Expedition & Hearts System:** Start with 3 hearts per run. Losing all 3 hearts sends you back to the Hub with all collected resources preserved.
* **10 Base Resources:** Credits 💰, Wood 🟤, Stone ⚪, Gold 🟡, Food 🍗, Tools 🛠️, Science 🧬, Fragments 🧩, Colors 🎨, Jokers 🃏.
* **Crafting & Advanced Items:** Fire 🔥, Bricks 🧱, Workers 👷, Houses 🏠, Reconstructed Photo, Photo Set, Photo Album, and the unique **1/1 Premium Photo Album**.
* **Mobile First Design:** Zero-scroll layout built specifically for smartphone viewports (`100dvh`).
* **Code-Based Save System:** Export and import progress using a custom alphanumeric code (100% client-side, zero LocalStorage dependency).

### 🚀 How to Run
Simply open `index.html` in any modern web browser or host it via GitHub Pages.

## 🇮🇹 Versione Italiana

### 🎮 Descrizione
**Tiles Journey** è un gioco strategico incrementale e di gestione risorse ottimizzato per dispositivi mobili. Gestisci le risorse, sali di livello senza limiti e parti per spedizioni dove ogni scelta fornisce materiali o nasconde insidie. Crea risorse avanzate nell'Hub per sbloccare oggetti unici!

### ✨ Caratteristiche Principali
* **Progressione Infinita:** Guadagni +1 EXP per ogni scelta effettuata. Il fabbisogno di esperienza aumenta ad ogni livello.
* **Sistema di Spedizioni e Cuori:** Ogni spedizione parte con 3 cuori. Azzerare i cuori riporta nell'Hub mantenendo tutte le risorse raccolte.
* **10 Risorse Base:** Crediti 💰, Legno 🟤, Pietra ⚪, Oro 🟡, Cibo 🍗, Utensili 🛠️, Scienza 🧬, Frammenti 🧩, Colori 🎨, Jolly 🃏.
* **Sistema di Ricette ed Oggetti Avanzati:** Fuoco 🔥, Mattoni 🧱, Lavoratori 👷, Case 🏠, Foto Ricomposta, Set Fotografico, Album Fotografico e il leggendario **Album Fotografico Premium 1/1**.
* **Design Mobile-First:** Layout senza scorrimento verticale adattato alle dimensioni degli smartphone.
* **Salvataggio tramite Codice:** Esporta e importa i tuoi salvataggi copiando un codice alfanumerico (senza memoria locale o tracciamento).
